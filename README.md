# rustgis-web

Generated GitHub Pages deployment for the [RustGIS](https://github.com/opengeos/RustGIS) web app, served at **<https://web.rustgis.app>**.

The `gh-pages` branch is replaced on every merge to RustGIS `main` by its `web-deploy.yml` workflow (a WebAssembly build of `apps/rustgis-web`). Do not edit it by hand.
